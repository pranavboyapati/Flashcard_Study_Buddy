## Overview

Flashcard Study Buddy is a versatile flashcard application designed to help users study and memorize information efficiently. Built using Unity and C#, the app allows users to create custom flashcards, organize them into decks, and track their progress over time.

## Installation & Setup

Clone the repo and open the Unity project:

```bash
git clone https://github.com/pranavboyapati/Flashcard_Study_Buddy.git
cd Flashcard_Study_Buddy
```
Then, open the project using any version of the Unity Editor released after 2021.
